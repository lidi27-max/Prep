Fix the grammar, together

Each sentence has one grammar mistake. Work with your partner in the breakout room:

  • Read the sentence aloud and decide what is wrong.
  • Edit the sentence in the box so it is correct, then press Check.
  • If you are stuck, press Hint. Read every explanation: these patterns appear in Build a Sentence.
  • Both partners help each other. There are no roles.
